# alien-tic-tac-toe-ai
Computer Game generated as part of workshop at All Things Open 2026

## Alien Tic-Tac-Toe
A one-player tic-tac-toe game in your browser. Every square you pick starts a short battle against an alien. Win the battle and the square gets your X; lose it and the alien gets an O. Get three X in a line to win.

## How to play
1. Open `index.html` on GitHub and click **Download raw file**.
2. Double-click the downloaded file. The game opens in your browser and works without an internet connection.
3. Pick an empty square to start a battle.
4. The alien attacks with Laser, then Shield, then Claw. Reply with **Shield** to Laser, **Blast** to Shield and **Dodge** to Claw.
5. A right reply costs the alien 1 health; a wrong one costs you 1. You each start with 2.
6. Three X in a line wins, three O loses, and a full board with no line is a draw. Press **Restart game** at any time to start over.

You can play with a mouse, the keyboard (Tab, Shift+Tab, Enter and Space) or by tapping on a phone.
